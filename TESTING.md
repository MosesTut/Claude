Complete end-to-end testing guide for developers and QA.

## Quick Start Testing

### 1. Start Backend (Terminal 1)

```bash
cd backend
docker-compose up -d

# Verify backend is running
curl http://localhost:8000/health
# Expected: {"status":"healthy","database":"connected"}
```

**API Documentation**: http://localhost:8000/docs

### 2. Start Mobile App (Terminal 2)

```bash
cd mobile
npm install
npm start

# Press 'i' for iOS Simulator
# OR
# Press 'a' for Android Emulator
```

## Backend API Testing

### Manual API Testing (using curl or Postman)

#### 1. Health Check
```bash
curl http://localhost:8000/health
```
**Expected**: `{"status":"healthy","database":"connected"}`

#### 2. Signup
```bash
curl -X POST http://localhost:8000/auth/signup \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "password": "password123",
    "ai_disclosure_accepted": true,
    "data_use_accepted": true
  }'
```
**Expected**: `{"access_token": "...", "token_type": "bearer", "user": {...}}`

#### 3. Login
```bash
curl -X POST http://localhost:8000/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "password": "password123"
  }'
```

#### 4. Save Preferences (Authenticated)
```bash
TOKEN="your-jwt-token-here"

curl -X POST http://localhost:8000/preferences \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "interests": ["Culture & Museums", "Food & Dining"],
    "food_preferences": ["Vegetarian"],
    "budget_level": "mid-range",
    "pace": "moderate",
    "trip_length_days": 3
  }'
```

#### 5. Get City Recommendations (AI)
```bash
curl -X GET http://localhost:8000/cities/recommendations \
  -H "Authorization: Bearer $TOKEN"
```
**Expected**: Takes 5-10 seconds, returns 3 cities

#### 6. Generate Itinerary (AI)
```bash
curl -X POST http://localhost:8000/itinerary/generate \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "city_name": "Lisbon",
    "country": "Portugal",
    "trip_length_days": 3
  }'
```
**Expected**: Takes 30-60 seconds, returns full itinerary

#### 7. Submit Feedback
```bash
curl -X POST http://localhost:8000/feedback \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "itinerary_id": "uuid-here",
    "feedback_type": "inaccurate",
    "comments": "Restaurant is closed"
  }'
```

#### 8. Delete Account (GDPR)
```bash
curl -X DELETE http://localhost:8000/user/account \
  -H "Authorization: Bearer $TOKEN"
```

## Troubleshooting

### Backend Won't Start

```bash
# Check Docker logs
docker-compose logs -f

# Common issues:
# 1. Port 8000 already in use
lsof -ti:8000 | xargs kill -9

# 2. PostgreSQL won't start
docker-compose down -v  # Remove volumes
docker-compose up -d

# 3. Missing ANTHROPIC_API_KEY
# Add to backend/.env:
ANTHROPIC_API_KEY=sk-ant-your-key-here
```

### Mobile Won't Connect to Backend

```bash
# Check mobile/.env
cat mobile/.env
# Should contain:
API_BASE_URL=http://localhost:8000

# For physical device, use computer's IP:
API_BASE_URL=http://192.168.1.100:8000
```

### Database Migrations Failed

```bash
cd backend

# Reset database
docker-compose down -v
docker-compose up -d

# Run migrations
alembic upgrade head
```
