## Added

### Backend (FastAPI + PostgreSQL + Anthropic Claude)

**API Endpoints (8 total)**:
- `POST /auth/signup` - User registration with AI disclosure consent
- `POST /auth/login` - JWT authentication
- `GET /user/me` - Get current user info
- `DELETE /user/account` - Delete account (GDPR/CCPA compliant)
- `POST /preferences` - Save travel preferences
- `GET /preferences` - Load saved preferences
- `GET /cities/recommendations` - AI-powered city recommendations (Claude 3.5 Sonnet)
- `POST /itinerary/generate` - AI-powered itinerary generation (30-60s)
- `GET /itinerary` - List user's itineraries
- `GET /itinerary/{id}` - Get specific itinerary
- `PATCH /itinerary/{id}/rating` - Rate itinerary (helpful/not helpful)
- `POST /feedback` - Submit feedback/report issues

**Database Models (5 tables)**:
- `users` - User accounts with consent tracking
- `preferences` - Travel preferences (interests, food, budget, pace)
- `itineraries` - AI-generated itineraries with metadata
- `feedback` - User feedback and issue reports
- `subscriptions` - Subscription tiers (free/pro)

**AI Integration**:
- Anthropic Claude 3.5 Sonnet (claude-3-5-sonnet-20241022)
- Multi-agent workflow:
  - City Selection Agent (recommends 3 cities)
  - Concierge Agent (generates day-by-day itinerary)
- Deterministic orchestration with prompt versioning (v1.0)
- Fallback to hardcoded cities if API fails

**Security & Authentication**:
- JWT tokens with 30-day expiration
- bcrypt password hashing
- Expo SecureStore integration (Keychain/Keystore)
- CORS middleware for mobile app

**Rate Limiting**:
- Free tier: 3 itineraries per month
- Pro tier: Unlimited (to be implemented with RevenueCat)

**DevOps**:
- Docker + docker-compose configuration
- Alembic database migrations
- Environment variable management
- Health check endpoint (`/health`)

## Fixed

### [1.0.1] - 2025-01-20 (Bug Fix Release)

Fixed 7 critical bugs that prevented the app from running:

1. **Missing Assets Directory** ✅
   - Created `/mobile/assets/` directory
   - Replaced logo/icon imports with emoji placeholders
   - Added .gitkeep with TODO for actual images

2. **Missing API Module Imports** ✅
   - Fixed AuthScreen, FeedbackScreen, SettingsScreen
   - Changed `import { authAPI } from '../api/auth'` → `import apiClient from '../services/api'`

3. **Navigation Type Mismatch** ✅
   - Fixed `Itinerary` route: `{ cityId, cityName }` → `{ itineraryId }`
   - Made `Auth` mode optional: `{ mode?: 'login' | 'signup' }`

4. **Conflicting Screen Implementations** ✅
   - Replaced old static SplashScreen with new auth-checking version
   - Added auto-navigation logic (Onboarding if logged out, Preferences if logged in)

5. **Duplicate Onboarding Screens** ✅
   - Deleted OnboardingWelcomeScreen.tsx (duplicate)
   - Kept OnboardingScreen.tsx (used by App.tsx)

6. **Old Screens Using Wrong API Client** ✅
   - Updated all API calls to match backend endpoints
   - AuthScreen: `POST /auth/signup`, `POST /auth/login`
   - FeedbackScreen: `POST /feedback`
   - SettingsScreen: `DELETE /user/account`

7. **Missing Config Files** ✅
   - Added `babel.config.js` for Expo + React Native Paper
   - Added `mobile/.gitignore` for node_modules, .expo, .env
