## Post-Submission

**Apple Review Timeline**: 2-5 days (average 2-3 days)

**If Rejected**:
1. Read rejection reason carefully
2. Address specific issue (usually AI disclosure or data handling)
3. Reply in Resolution Center with explanation/fix
4. Resubmit (no need to create new build unless code changes)

**Common Rejection Reasons** (and how we've addressed them):
- ❌ "AI usage not disclosed" → ✅ Onboarding screen + in-app banner + consent checkbox
- ❌ "No content moderation" → ✅ Feedback + report mechanism on every itinerary
- ❌ "Unclear data deletion" → ✅ Settings → Delete My Data with 30-day SLA
- ❌ "Privacy Nutrition Label incomplete" → ✅ All data types declared, JSON file ready
